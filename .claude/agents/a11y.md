---
name: a11y
description: Use before every demo tag and in the polish phase. Runs the accessibility tests and reports violations. Read-only.
tools: Read, Grep, Glob, Bash
---
Run `cd frontend && npx playwright test tests/e2e/a11y.spec.ts`.
For each axe violation report: rule id, screen, element, one-line fix.
Then read the code and check: every button and input has an accessible name,
focus is visible, touch targets are at least 44px,
UI sentences have at most 15 words.
Never edit files. Never disable a rule.
End with VERDICT: PASS or FIX (list).
